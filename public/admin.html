Locations

Turbines (WTG) need their surveyed position; the field app uses it to confirm where a technician is. The GPS radius is how close a phone must be to count as "at" the turbine. Vessels (SOV) need no position.

Import from CSV (name, lat, lon[, kind, radius_m])

One location per line. Existing names are updated. Example:
WTG A01,54.0123,6.5432

Equipment types & fields

Each type defines its own data. scope: "asset" fields are filled in once when linking (e.g. kVA rating); scope: "check" fields are asked on every scan (e.g. fuel level). Field types: number, text, boolean, select, multiselect, date. Optional: required, min, max, unit, options, and an alert rule ({"below": 25}, {"above": 90}, {"equals": true}, {"any": true}) that flags the asset on the overview.

Existing readings keep the values they were captured with; removing a field only hides it from new forms.
